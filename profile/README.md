# AI-Agent-Lab

AI 应用研究实验室，聚焦 **RAG、MCP、AI Agent 与本地大模型应用**，通过独立项目探索核心原理、系统架构和工程实践。

## 项目

| Repository | 方向 | 状态 |
| --- | --- | --- |
| [mcp-demo](https://github.com/ai-agent-lab-cn/mcp-demo) | MCP 基础、资源访问与 Prompt 示例 | 已完成 |
| [rag-core-guide](https://github.com/ai-agent-lab-cn/rag-core-guide) | 基础 RAG 原理与最小实现 | 已完成 |
| [rag-enterprise](https://github.com/ai-agent-lab-cn/rag-enterprise) | 企业级 RAG 架构与工程实践 | 已完成 |
| [zr-langChain](https://github.com/ai-agent-lab-cn/zr-langChain) | LangChain、LangGraph、LangSmith 学习与实战系列 | 已完成 |
| [realTime](https://github.com/ai-agent-lab-cn/realTime) | 基于 llama.cpp 与 Qwen3-4B-Instruct-2507（Q4_K_M）的本地大模型翻译及实时中文字幕工具 | 已完成 |
| [ai-manju](https://github.com/ai-agent-lab-cn/ai-manju) | AI 漫剧制作工具 | 计划中 |

## 研究方向

- **RAG 基础与评估**：文档分块、检索、重排、生成与效果评估
- **企业级 RAG**：知识库架构、权限、安全、可观测性与部署
- **MCP**：协议原理、资源访问、Prompt 与工具集成
- **AI Agent**：工作流编排、工具调用与多智能体协作
- **本地大模型应用**：模型推理、翻译与实时字幕
- **AI 产品工程**：面向真实场景的产品设计、系统实现与迭代

## 组织方式

每个 AI 应用或研究主题均使用独立的 Repository，分别维护代码、文档、Issue 与版本演进，使各项目的学习路径和工程实践保持清晰。
